### 1.1 核心设计原则

1. **前端不直连 Legado**：所有请求经过我方 Spring Boot 后端中转，便于统一鉴权、日志、限流。
2. **用户系统独立**：不使用 Legado 的用户体系，书架和进度全部存储在我方 MySQL 中。
3. **章节预处理**：搜索后用户选择书籍时，后端异步下载所有章节并按章节上传到阿里云 OSS，前端按需拉取。
4. **前端本地缓存**：前端缓存章节内容到本地存储，减少流量和 OSS 访问次数。
5. **进度双写**：前端本地记录进度，阅读时定时上报后端（防止频繁请求）。

## 2. 数据库表结构

> 使用 Flyway 进行数据库版本管理，脚本位于 `backend/src/main/resources/db/migration/`

### 2.1 用户表 `t_user`

```sql
CREATE TABLE t_user (
    id          BIGINT AUTO_INCREMENT PRIMARY KEY COMMENT '用户ID',
    user_id     VARCHAR(64)  NOT NULL UNIQUE COMMENT '用户唯一标识（UUID）',
    nickname    VARCHAR(64)  NOT NULL DEFAULT '' COMMENT '昵称',
    avatar      VARCHAR(512) COMMENT '头像URL',
    token       VARCHAR(256) NOT NULL COMMENT 'JWT Token（可刷新）',
    created_at  DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '注册时间',
    updated_at  DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    INDEX idx_user_id (user_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';
```

### 2.2 书架表 `t_bookshelf`

```sql
CREATE TABLE t_bookshelf (
    id              BIGINT AUTO_INCREMENT PRIMARY KEY COMMENT '主键',
    user_id         VARCHAR(64)  NOT NULL COMMENT '用户ID',
    book_id         VARCHAR(128) NOT NULL COMMENT '书籍唯一ID（由bookUrl的MD5生成）',
    book_url        TEXT         NOT NULL COMMENT 'Legado书籍URL（原始）',
    book_name       VARCHAR(256) NOT NULL COMMENT '书名',
    author          VARCHAR(128) NOT NULL DEFAULT '' COMMENT '作者',
    cover_oss_url   VARCHAR(512) COMMENT 'OSS封面图片地址',
    intro           TEXT COMMENT '简介',
    origin          VARCHAR(512) COMMENT '书源URL',
    origin_name     VARCHAR(128) COMMENT '书源名称',
    total_chapters  INT          NOT NULL DEFAULT 0 COMMENT '总章节数',
    download_status TINYINT      NOT NULL DEFAULT 0 COMMENT '下载状态: 0=待处理 1=下载中 2=完成 3=失败',
    created_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '加入书架时间',
    updated_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    UNIQUE KEY uk_user_book (user_id, book_id),
    INDEX idx_user_id (user_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='书架表';
```

### 2.3 章节元数据表 `t_chapter`

```sql
CREATE TABLE t_chapter (

    is_vip      TINYINT(1)   NOT NULL DEFAULT 0 COMMENT '是否VIP章节',

    updated_at  DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    UNIQUE KEY uk_book_chapter (book_id, chapter_idx),
    INDEX idx_book_id (book_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='章节元数据表';
```

## 3. 后端接口文档

### 基础约定

- **Base URL**: `https://your-domain.com/api/v1`
- **请求格式**: `Content-Type: application/json`
- **认证方式**: `Authorization: Bearer {JWT token}` 请求头
- **统一返回格式**:

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

| code | 含义 |
|------|------|
| 200  | 成功 |
| 400  | 参数错误 |
| 401  | 未认证 |
| 403  | 无权限 |
| 404  | 资源不存在 |
| 500  | 服务器内部错误 |
| 1001 | Legado 服务不可用 |
| 1002 | 书籍下载中 |
| 1003 | 章节不存在 |

#### 3.2.2 触发书籍下载并加入书架

> 调用时机：用户在搜索结果中点击「阅读」后调用，后端异步下载章节到 OSS。
> 内部逻辑：
> 1. 将书籍信息写入 `t_bookshelf`（用户书架）
> 2. 调用 Legado 的 `saveBook` 接口将书保存到 Legado 服务端缓存
> 3. 异步调用 Legado 的 `getChapterList` 获取章节列表
> 4. 异步逐章节调用 Legado 的 `getBookContent` 获取内容
> 5. 将每个章节内容上传到阿里云 OSS（路径：`books/{bookId}/{chapterIdx}.txt`）
> 6. 封面图片下载后上传到 OSS（路径：`books/{bookId}/cover.jpg`）

```json

  "intro": "简介",
  "kind": "玄幻",
  "origin": "书源URL",
```

```json
{
  "code": 200,
  "data": {
    "bookId": "md5_of_book_url",
    "downloadStatus": 1,
    "message": "书籍已加入书架，正在后台下载章节..."
  }
}
```

## 4. 后端核心逻辑说明

### 4.1 Legado 服务端认证适配

Legado 服务端默认无鉴权（或基本HTTP认证），后端需在配置文件中配置：

```yaml
legado:
  base-url: http://legado-server:1234    # Legado HTTP 接口地址
  ws-url: ws://legado-server:1235        # Legado WebSocket 接口地址
  username: ""                           # 如果开启了认证，填写用户名
  password: ""                           # 如果开启了认证，填写密码
  connect-timeout: 10000                 # 连接超时（毫秒）
  read-timeout: 60000                    # 读取超时（毫秒）
```

后端的 `LegadoHttpClient` 会自动在每次请求时添加认证头（如果配置了用户名密码）。

### 4.2 书籍 ID 生成规则

书籍 ID 是书籍 URL（`bookUrl`）的 MD5 哈希值，保证唯一性且固定长度：

```kotlin
fun generateBookId(bookUrl: String): String = DigestUtils.md5DigestAsHex(bookUrl.toByteArray())
```

### 4.3 章节下载流程（异步）

```
1. 保存书架记录（status=0）
2. 提交异步任务
3. 调用 Legado: POST /saveBook（将书保存到 Legado 缓存）
4. 调用 Legado: GET /getChapterList?url={bookUrl}（获取章节列表）
5. 保存章节元数据到 t_chapter 表
6. 逐章节（并发度控制为3）：
   a. 调用 Legado: GET /getBookContent?url={bookUrl}&index={idx}
   b. 内容上传到 OSS: books/{bookId}/{idx}.txt
   c. 更新 t_chapter 的 oss_key 字段
   d. 更新 t_download_task 的 done_chapters
7. 下载封面图并上传到 OSS: books/{bookId}/cover.jpg
8. 更新 t_bookshelf 的 download_status=2, cover_oss_url, total_chapters
```

### 4.4 OSS 预签名 URL 策略

- URL 有效期：**1小时**（3600秒）
- 前端收到 URL 后立即缓存内容到本地，不依赖 URL 过期时间
- 后端不缓存预签名 URL，每次请求都生成新的

### 4.5 并发控制

- 章节下载：使用 `Semaphore(3)` 控制并发，避免对 Legado 和 OSS 的请求过多
- 搜索：WebSocket 连接有超时机制（15秒），超时后断开并返回已收集的结果

## 5. 前端页面流程

### 5.1 页面结构

```
pages/
├── index/index.uvue        # 书架主页（TabBar首页）
├── search/search.uvue      # 搜索页
├── chapters/chapters.uvue  # 章节列表页
└── reader/reader.uvue      # 阅读器页
```

### 5.2 书架页流程

```
App启动
  └─→ 检查本地token
        ├─→ 无token: 调用/user/login获取token
        └─→ 有token: 调用GET /bookshelf获取书架
                        └─→ 展示封面网格/列表
                              └─→ 点击书籍
                                    └─→ 跳转阅读器（带bookId、进度）
```

### 5.3 搜索页流程

```
用户输入关键词 → 点击搜索
  └─→ 调用GET /search/books
        └─→ 展示搜索结果列表
              └─→ 用户点击「阅读」
                    └─→ 调用POST /books/add
                          └─→ 轮询GET /books/{bookId}/download-status
                                └─→ status=2时跳转阅读器
```

### 5.4 章节列表页流程

```
进入章节列表页（带bookId）
  └─→ 检查本地缓存的章节列表
        ├─→ 有缓存: 直接展示
        └─→ 无缓存: 调用GET /books/{bookId}/chapters
                      └─→ 分页加载所有章节
                            └─→ 缓存到本地（uni.setStorageSync）
                                  └─→ 点击章节
                                        └─→ 跳转阅读器（带chapterIdx）
```

### 5.5 阅读器页流程

```
进入阅读器（带bookId、chapterIdx）
  └─→ 从服务端获取最新进度（与本地进度取较新的）
        └─→ 调用GET /books/{bookId}/chapters/{idx}/url
              └─→ 获取OSS预签名URL
                    └─→ 下载章节内容（文本）
                          └─→ 缓存到本地
                                └─→ 渲染文字（支持翻页/滚动）
                                      └─→ 同时预加载前后各2章
                                            ├─→ 翻页时更新进度
                                            │   （节流30秒上报）
                                            └─→ 退出时立即上报进度
```

### 5.6 本地缓存策略

| 缓存类型 | 缓存Key | 缓存时效 | 说明 |
|----------|---------|---------|------|
| 章节列表 | `chapters_{bookId}` | 永久 | 章节列表不会频繁变化 |
| 章节内容 | `content_{bookId}_{idx}` | 永久（最多缓存100章） | LRU淘汰策略 |
| 阅读进度 | `progress_{bookId}` | 永久 | 本地与服务端取较新 |
| 搜索历史 | `search_history` | 永久 | 最多保存20条 |

## 6. 阿里云 OSS 存储规范

### 6.1 目录结构

```
Bucket: your-reader-bucket
└── books/
    └── {bookId}/           # bookId = bookUrl 的 MD5 值
        ├── cover.jpg       # 封面图片
        ├── 0.txt           # 第1章内容（纯文本UTF-8）
        ├── 1.txt           # 第2章内容
        ├── 2.txt           # 第3章内容
        └── ...
```

### 6.2 OSS 配置

```yaml
aliyun:
  oss:
    endpoint: oss-cn-hangzhou.aliyuncs.com
    access-key-id: your-access-key-id
    access-key-secret: your-access-key-secret
    bucket-name: your-reader-bucket
    cdn-domain: https://cdn.your-domain.com   # 可选，CDN加速域名
    presign-expires: 3600                      # 预签名URL有效期（秒）
```

### 6.3 章节内容格式

```
第一章 云岚宗
    这是正文内容，纯文本格式...
    段落之间使用\n\n分隔...
```

## 7. 与 Legado 服务端交互说明

### 7.1 Legado 服务调用清单

| 用途 | 方法 | URL | 调用时机 |
|------|------|-----|---------|
| 搜索书籍 | WebSocket | `ws://{legado}/searchBook` | 用户搜索时 |
| 保存书籍到Legado缓存 | POST | `{legado}/saveBook` | 用户加入书架时 |
| 获取章节列表 | GET | `{legado}/getChapterList?url={bookUrl}` | 下载任务中 |
| 获取章节内容 | GET | `{legado}/getBookContent?url={bookUrl}&index={idx}` | 下载任务中 |
| 获取封面图 | GET | `{legado}/cover?path={coverUrl}` | 下载封面时 |

### 7.2 搜索 WebSocket 交互协议

```
客户端（后端） → Legado WebSocket (ws://{legado}/searchBook)
客户端发送: {"key": "斗破苍穹"}

Legado 返回多条消息，每条消息为一本书的JSON：
{
  "bookUrl": "...",
  "name": "...",
  "author": "...",
  ...
}

连接关闭时表示搜索结束。
```

### 7.3 认证处理

Legado 服务端可以在设置中开启 Web 服务密码，格式为 HTTP Basic Auth：

```kotlin
// 在 OkHttp 请求中添加 Basic Auth 头
fun buildAuthHeader(username: String, password: String): String {
    val credentials = "$username:$password"
    return "Basic " + Base64.getEncoder().encodeToString(credentials.toByteArray())
}
```

## 8. 部署说明

### 8.1 Docker Compose 部署

```yaml
# docker-compose.yml
version: '3.8'
services:
  legado:
    image: ghcr.io/gedoor/legado:latest
    container_name: legado-server
    ports:
      - "1234:1234"
      - "1235:1235"
    volumes:
      - ./legado-data:/legado/data
    restart: unless-stopped

  mysql:
    image: mysql:8.0
    container_name: reader-mysql
    environment:
      MYSQL_ROOT_PASSWORD: your_password
      MYSQL_DATABASE: reader_db
    volumes:
      - ./mysql-data:/var/lib/mysql
    ports:
      - "3306:3306"
    restart: unless-stopped

  backend:
    image: reader-backend:latest
    container_name: reader-backend
    depends_on:
      - mysql
      - legado
    environment:
      SPRING_DATASOURCE_URL: jdbc:mysql://mysql:3306/reader_db?useUnicode=true&characterEncoding=utf8
      SPRING_DATASOURCE_USERNAME: root
      SPRING_DATASOURCE_PASSWORD: your_password
      LEGADO_BASE_URL: http://legado:1234
      LEGADO_WS_URL: ws://legado:1235
      ALIYUN_OSS_ACCESS_KEY_ID: xxx
      ALIYUN_OSS_ACCESS_KEY_SECRET: xxx
      ALIYUN_OSS_BUCKET_NAME: your-bucket
      JWT_SECRET: your-jwt-secret-at-least-32-chars
    ports:
      - "8080:8080"
    restart: unless-stopped
```

### 8.2 环境变量清单

| 环境变量 | 必填 | 说明 |
|----------|------|------|
| SPRING_DATASOURCE_URL | 是 | MySQL 连接 URL |
| SPRING_DATASOURCE_USERNAME | 是 | MySQL 用户名 |
| SPRING_DATASOURCE_PASSWORD | 是 | MySQL 密码 |
| LEGADO_BASE_URL | 是 | Legado HTTP 地址 |
| LEGADO_WS_URL | 是 | Legado WebSocket 地址 |
| LEGADO_USERNAME | 否 | Legado 认证用户名 |
| LEGADO_PASSWORD | 否 | Legado 认证密码 |
| ALIYUN_OSS_ENDPOINT | 是 | OSS Endpoint |
| ALIYUN_OSS_ACCESS_KEY_ID | 是 | OSS AccessKey ID |
| ALIYUN_OSS_ACCESS_KEY_SECRET | 是 | OSS AccessKey Secret |
| ALIYUN_OSS_BUCKET_NAME | 是 | OSS Bucket 名称 |
| ALIYUN_OSS_CDN_DOMAIN | 否 | CDN 加速域名 |
| JWT_SECRET | 是 | JWT 签名密钥（至少32字符） |
| JWT_EXPIRE_HOURS | 否 | JWT 有效期（小时），默认720 |

## 9. 开发规范

### 9.1 代码规范

- 所有类、方法、重要逻辑必须添加**中文注释**
- 使用 `logger.info("[模块名] 操作描述 参数={}"，参数)` 格式打印日志
- 异常必须捕获并记录，不允许静默吞掉异常
- 所有数据库操作使用事务注解 `@Transactional`

### 9.2 错误处理规范

- Controller 层统一使用 `@ExceptionHandler` 处理异常
- Service 层抛出业务异常时使用自定义 `BusinessException`
- 所有 Legado 调用失败时返回 `code=1001`，不影响其他功能

### 9.3 日志规范

```kotlin
// 标准日志格式
logger.info("[搜索] 开始搜索 keyword={}, userId={}", keyword, userId)
logger.warn("[下载] 章节下载失败 bookId={}, chapterIdx={}, error={}", bookId, idx, e.message)
logger.error("[OSS] 上传失败 key={}", key, e)
```
